## Requirements

Ensure you have the following installed on your system

### Git

```
pacman -S git
```

### Stow

```
pacman -S stow
```

## Installation

First, check out the dotfiles repo in your $HOME directory using git

```
$ git clone https://github.com/rahul-797/dotfiles.git
$ cd dotfiles
```

Use Stow to create symlinks

```
$ stow .
```
